About LEVoiceCall

Version 1.0.0

LEVoiceCall is a browser-based communication website for creating independent voice and video call rooms. Each room has its own unique join code, participants, and privacy settings.

Key Features

  • Facebook authentication (public profile only)
  • Multiple simultaneous independent call rooms
  • Voice calls and video calls
  • Unique join codes — one code = one room
  • Best-effort screenshot & screen-recording protection (browser limits apply)
  • Creator ownership: when the creator leaves, only that room shuts down
  • Responsive design for mobile and desktop browsers

Privacy & Permissions

Camera and microphone access are requested only when you create or join a call that needs them. LEVoiceCall never activates devices secretly. All device permissions use standard browser APIs and respect your browser’s security settings.

Technology

Built as a real website for Vercel. Uses WebRTC for media, serverless API routes for room state, and the Facebook JavaScript SDK for authentication.

Note: Full multi-user media requires a secure context (HTTPS) and working STUN/TURN. Configure your Facebook App ID and Vercel environment variables for production use.
